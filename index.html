Respaldos

Protegé los datos del negocio y recuperalos cuando cambies de computadora o navegador.

📥

Descargar copia de seguridad

Guarda productos, clientes, ventas y movimientos en un archivo JSON. Hacé una copia periódicamente y guardala en un lugar seguro.

📤

Restaurar copia de seguridad

Importá un archivo generado por este sistema. La restauración reemplaza todos los datos actuales: descargá antes un respaldo.

⚠️

Borrar todos los datos

Elimina permanentemente el inventario, los clientes, las ventas y el historial de este navegador. No se puede deshacer sin un respaldo.

Importante: Los datos se guardan únicamente en este navegador y dispositivo. No se sincronizan entre equipos ni constituyen una base de datos en la nube. No uses el modo incógnito ni borres los datos del sitio. Este sistema emite comprobantes internos, no facturas fiscales.
